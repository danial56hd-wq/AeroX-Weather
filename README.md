## 📖 نبذة عن المشروع | About

**AERO-X Weather** هو تطبيق ويب متكامل لرصد الطقس العالمي بواجهة سايبر مستقبلية مذهلة. يجمع بين البيانات الجوية الحية وخرائط الطبقات التفاعلية وتحليلات بيئية متقدمة، مقدماً تجربة مستخدم لا مثيل لها.

**AERO-X Weather** is a full-featured global weather monitoring web app with a stunning cyber-futuristic UI. It combines live atmospheric data, interactive layered maps, and advanced environmental analytics — delivering an unmatched user experience.

## ✨ الميزات الرئيسية | Key Features

### 🌍 رصد جوي عالمي | Global Weather Monitoring
- **بيانات حية آنية** من OpenWeatherMap API
- عرض درجات الحرارة الحالية، الملموسة، الدنيا والقصوى
- حالة الطقس مع وصف تفصيلي دقيق

### 🗺️ خريطة جوية تفاعلية | Interactive Atmospheric Map
طبقات خريطة متعددة قابلة للتفعيل في آنٍ واحد:

| الطبقة | الوصف |
|--------|-------|
| 💨 حركة الرياح | تصور حي لاتجاهات وسرعات الرياح |
| 🌧️ رادار الأمطار | تتبع هطول الأمطار في الوقت الفعلي |
| 🌡️ الحرارة الأرضية | خريطة حرارة تضاريسية للسطح |
| 🛰️ الأقمار الصناعية | صور سحابية من الأقمار الصناعية |
| 🌊 أمواج البحر | رصد حركة أمواج المحيطات |
| ❄️ تراكم الثلوج | خريطة تراكم الثلوج العالمية |

### 📊 لوحة بيانات شاملة | Full Data Dashboard
- 💧 **الرطوبة** — نسبة مئوية دقيقة
- 🌬️ **الرياح** — السرعة والاتجاه
- 👁️ **الرؤية** — مدى الرؤية بالكيلومترات
- ⬇️ **الضغط الجوي** — بوحدة hPa
- ☀️ **مؤشر الأشعة فوق البنفسجية** — مع تصنيف الخطر
- 🌅 **الشروق والغروب** — توقيت دقيق

### 🌿 جودة الهواء | Air Quality Index
تحليل متقدم لجسيمات الهواء:
- **PM2.5** — الجسيمات الدقيقة الصغيرة
- **PM10** — الجسيمات الدقيقة الكبيرة
- **O₃** — مستوى الأوزون
- تصنيف تلقائي: جيد / معتدل / غير صحي / خطر

### 📅 توقعات 7 أيام | 7-Day Forecast
- توقعات يومية تفصيلية
- رسم بياني ساعي للاتجاهات (HOURLY TREND)
- أيقونات حالة الطقس لكل يوم

### ▶️ الطريقة الثانية: تشغيل محلي
```bash
# 1. انسخ المستودع
git clone https://codeberg.org/nidalwatfa/AeroX-Weather.git

# 2. ادخل المجلد
cd AeroX-Weather

# 3. افتح الملف الرئيسي في متصفحك
open index.html
# أو على Windows:
start index.html
```

---

### ▶️ الطريقة الثالثة: خادم محلي (مُوصى به)
```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node.js
npx serve .

# ثم افتح المتصفح على:
# http://localhost:8080
```

## 🔑 دليل المستخدم | User Guide

### الخطوة 1️⃣ — إضافة مفتاح API (اختياري)

> **بدون مفتاح:** يعمل التطبيق في **وضع العرض** مع بيانات نموذجية  
> **مع مفتاح:** بيانات حية آنية من أي مدينة في العالم

```
1. اضغط على أيقونة 🔑 في الشريط العلوي
2. اذهب إلى openweathermap.org وأنشئ حساباً مجانياً
3. انسخ مفتاح API الخاص بك
4. الصقه في الحقل واضغط "حفظ وتطبيق"
5. يُحفظ المفتاح تلقائياً في متصفحك
```

### الخطوة 2️⃣ — البحث عن مدينة
```
اكتب اسم أي مدينة في العالم في شريط البحث
→ ستظهر البيانات الجوية الكاملة فوراً
```

### الخطوة 3️⃣ — استكشاف طبقات الخريطة
```
اضغط على زر "الخريطة الجوية"
→ فعّل/أوقف أي طبقة تريدها
→ يمكنك دمج طبقات متعددة معاً
```

### الخطوة 4️⃣ — تغيير اللغة
```
اضغط على علم اللغة في الزاوية
→ اختر من 10 لغات عالمية
→ تتغير الواجهة كاملاً فوراً
```

### الخطوة 5️⃣ — مشاركة الطقس
```
اضغط على أيقونة المشاركة
→ اختر المنصة المفضلة
→ أرسل لأصدقائك حالة الطقس
```
